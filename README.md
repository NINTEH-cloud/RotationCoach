# Rotation Coach

A rotation helper for every profession and elite specialization in Guild Wars 2, as a [Raidcore Nexus](https://raidcore.gg/Nexus) addon.

## What's inside

- Build, record and follow rotations, with an overlay that shows the next skills.
- Import builds and share rotations with a short code.

The addon is available in Dutch, English and German.

## Requirements

- [ArcDPS](https://www.deltaconnected.com/arcdps/) is recommended. The addon uses its combat data, directly or through [DPS Buddy](https://github.com/NINTEH-cloud/DpsBuddy).

## Installation

1. Install [Raidcore Nexus](https://raidcore.gg/Nexus).
2. Download `RotationCoach.dll` from the [latest release](https://github.com/NINTEH-cloud/RotationCoach/releases/latest).
3. Put it in `Guild Wars 2/addons/` and load it in the Nexus addon library.

Updates arrive automatically through Nexus.

## Reporting a bug or idea

Open an [issue](https://github.com/NINTEH-cloud/RotationCoach/issues), or use the **Report a bug** button in the addon's settings. A screenshot and your addon version (shown in the settings) help a lot.

## Fair play

The addon does not read or change game memory and does not automate gameplay. Every key it sends is a single press that you trigger yourself, never a macro.
